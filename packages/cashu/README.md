# @kepler/cashu

## Purpose

The `@kepler/cashu` package is the protocol adapter for Cashu operations in the Kepler agent wallet. It provides mint communication, ecash token parsing, melt, and swap operations with automated validation and typed error handling.

## Required environment variables

- `CASHU_MINT_URL`: Primary Cashu mint URL (must use http or https scheme).
- `CASHU_MINT_URL_FALLBACK`: Optional fallback Cashu mint URL (must use http or https scheme when provided).
- `CASHU_UNIT`: Cashu currency unit (`sat` or `msat`, defaults to `sat` if unset).
- `CASHU_REQUEST_TIMEOUT_MS`: Request timeout in milliseconds (positive integer, defaults to `15000`).
- `CASHU_TEST_TOKEN`: Optional public test ecash token string (integration test only).

## Public API

### CashuClient

```typescript
class CashuClient {
  constructor(config: CashuConfig, logger: KeplerLogger);
  getMintInfo(url?: string): Promise<CashuMintInfo>;
  mint(amountSats: bigint, memo?: string): Promise<CashuMintResult>;
  checkMintQuote(quote: string): Promise<CashuMintQuote>;
  mintTokens(quote: string, amountSats: bigint): Promise<CashuMintResult>;
  melt(bolt11: string, amountSats?: bigint, proofs?: CashuProof[] | CashuToken): Promise<CashuMeltResult>;
  swap(token: CashuToken, amountSats: bigint): Promise<CashuSwapResult>;
  restore(blindedMessages: string[]): Promise<CashuProof[]>;
  balance(token: CashuToken): bigint;
  mergeTokens(tokens: CashuToken[]): CashuToken;
}
```

### CashuConfig

```typescript
class CashuConfig {
  static fromEnv(env?: Record<string, string | undefined>): CashuConfig;
  constructor(params: CashuConfigParams);
  readonly mintUrl: string;
  readonly fallbackMintUrl: string | null;
  readonly unit: 'sat' | 'msat';
  readonly requestTimeoutMs: number;
}
```

### CashuTokenCodec

```typescript
class CashuTokenCodec {
  static encode(token: CashuToken): string;
  static decode(encoded: string): CashuToken;
  static toTokenReference(token: string): string;
}
```

### Types

- `CashuMintInfo`: Metadata and supported NUT operations for a Cashu mint.
- `CashuProof`: Single ecash proof with `amount: bigint`.
- `CashuToken`: Ecash token containing mint, unit, proofs array, and optional memo.
- `CashuMintQuote`: Mint quote with `amount: bigint` and quote state.
- `CashuMeltQuote`: Melt quote with `amount: bigint`, `feeReserve: bigint`, and quote state.
- `CashuMintResult`: Result of minting containing quote and token.
- `CashuMeltResult`: Result of melting ecash tokens.
- `CashuSwapResult`: Result of swapping ecash tokens.
- `CashuBalance`: Token balance with `total: bigint` and `byMint: Record<string, bigint>`.

### Errors

- `CashuConfigError`: Thrown when configuration variables are missing or malformed (`CASHU_CONFIG_ERROR`).
- `CashuNetworkError`: Thrown on mint network transport failure or unexpected HTTP error status (`CASHU_NETWORK_ERROR`).
- `CashuMintError`: Thrown on mint-specific errors or keyset validation failures (`CASHU_MINT_ERROR`).
- `CashuMeltError`: Thrown when melting ecash tokens fails (`CASHU_MELT_ERROR`).
- `CashuSwapError`: Thrown when token split or swap operations fail (`CASHU_SWAP_ERROR`).
- `CashuTokenError`: Thrown when ecash token structure or proof verification fails (`CASHU_TOKEN_ERROR`).
- `CashuParseError`: Thrown when ecash token string or serialization cannot be parsed (`CASHU_PARSE_ERROR`). Context input is truncated to 128 characters.

## Known limitations

- Single mint per call. No cross-mint atomic swaps.
- No deterministic secret derivation. Proofs are generated by the SDK.
- No automatic proof backup. NUT-09 restore is available but not automatic.
- Integration tests do not move real value.
